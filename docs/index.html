Install Rust (10 minutes, once)

On macOS or Linux, paste this into a terminal and accept the defaults:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

On Windows, download and run rustup-init.exe from rustup.rs. Then check it worked:

rustc --version
cargo --version
rustup component add clippy rustfmt

No install yet? Every runnable example in the slides has a Run button that uses the online Rust Playground.
