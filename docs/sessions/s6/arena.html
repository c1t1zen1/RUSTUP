Mission

Like cargo run -- map.txt script.txt: Robbie starts on the first tile that isn't a wall, facing East, with a battery of 50.


      

        The rules in one screen
        
    
          
  • Tiles: . floor, # wall, P a spare part. (0, 0) is top left; y grows going South.
    • 
          
  • Commands, one per line, any case: forward, forward N, left, right, pick, wait. Lines starting with # are notes.
    • 
          
  • Each tile forward costs 1 battery. Turns, picks and waits are free.
    • 
          
  • A wall or the edge ahead is a bump: it costs the battery, the bot stays put, and the rest of that forward is dropped.
    • 
          
  • Trying to move with battery 0 makes a bot flat. A flat bot ignores everything after.

      Stretch goal: put your Rust in here
      
  
      The Arena is JavaScript. The stretch goal is to replace it with your library. Build it for the web with wasm-pack and expose one function, and this page could call your code instead of its own:
      

      // in robbie-mc/src/lib.rs, behind a "wasm" feature
#[wasm_bindgen]
pub fn run_mission_json(text: &str) -> String {
    match Mission::from_json(text).and_then(|m| run_mission(&m)) {
        Ok(report) => report.to_json(),
        Err(e) => format!("error: {e}"),
    }
}
