Learning goals

By the end of Session 2 a student can:

  1. Explain the stack and the heap, and draw what a String looks like in memory.
  2. State the three ownership rules and say where any value is dropped.
  3. Tell a move from a Copy, and choose deliberately when to .clone().
  4. Borrow with & and &mut, and apply "many readers or one writer".
  5. Slice strings and arrays, and prefer &str and &[T] parameters.
  6. Recognise E0382, E0499, E0502, E0594/E0596 and E0106 and fix each one.

Before class

  • Grade Homework 1 and pick two contrasting battery_bar solutions to show (a loop and a repeat version are ideal).
  • Open labs/lab2-fix-the-borrow-checker and run cargo build --bin puzzle1 once so students see the same first error you do.
  • Have a whiteboard ready for the stack and heap picture. You'll redraw it at least three times.
  • Keep the three ownership rules written up for the whole session.

Deeper notes by topic

Why moves exist

If let b = a; copied only the stack record of a String, two records would point at one heap block and both would free it at the end of the scope. That double free is undefined behaviour in C. Rust's choice is to transfer responsibility: a becomes unusable, and only b frees. No runtime cost: a move is a 24-byte memcpy of the stack record, and the compiler may elide even that.

Copy is a marker

Copy is a trait that says "duplicating my bytes is a valid copy". A type can only be Copy if all its parts are and it doesn't implement Drop. Students will meet #[derive(Clone, Copy)] on their own structs in Session 3; tease it now.

Non-lexical lifetimes

Since the 2018 edition, a borrow ends at its last use, not at the end of its block. This is why reordering fixes so many E0502s. When a student asks "but the variable is still in scope!", the answer is that scope and borrow duration are different things.

Deref coercion

&String becomes &str automatically because String implements Deref<Target = str>. Same for &Vec<T> to &[T]. This is why clippy's ptr_arg lint tells you to take slices.

Lifetimes, only as much as needed

The elision rules: each input reference gets its own lifetime; if there's exactly one input lifetime, the output gets it; if there's &self, the output gets self's. Only when those don't decide it must you write 'a. Don't teach the rules today; just show longer and promise Session 4.

Puzzle 7 solution (the boss level) 
// Puzzle 7 solution: take &str and return a slice of it. No new String is allocated.
fn first_word(text: &str) -> &str {
    for (i, b) in text.bytes().enumerate() {
        if b == b' ' {
            return &text[..i];
        }
    }
    text
}

fn main() {
    let owned = String::from("rotate left 90");
    println!("{}", first_word(&owned));
    println!("{}", first_word("wave hello"));
}

Homework 2 solution and grading

Reference solution: src/lib.rs 
//! Homework 2: Log Scanner. Reference solution.

/// Returns the first word of `text`: everything before the first space.
pub fn first_word(text: &str) -> &str {
    for (i, b) in text.bytes().enumerate() {
        if b == b' ' {
            return &text[..i];
        }
    }
    text
}

/// Counts the lines in `log` whose level is `level`.
pub fn count_level(log: &str, level: &str) -> usize {
    let tag = format!("[{level}]");
    let mut count = 0;
    for line in log.lines() {
        if line.starts_with(&tag) {
            count += 1;
        }
    }
    count
}

/// Returns the longest line in `log`; the first one wins a tie.
pub fn longest_line(log: &str) -> &str {
    let mut best = "";
    for line in log.lines() {
        if line.len() > best.len() {
            best = line;
        }
    }
    best
}

/// Replaces every occurrence of `secret` with the same number of stars.
pub fn redact(line: &str, secret: &str) -> String {
    line.replace(secret, &"*".repeat(secret.len()))
}

/// Uppercases `line` in place and adds `!`.
pub fn shout(line: &mut String) {
    *line = line.to_uppercase();
    line.push('!');
}

/// One-line report: line count, then each level's count.
pub fn summary(log: &str) -> String {
    format!(
        "{} lines: {} ERROR, {} WARN, {} INFO",
        log.lines().count(),
        count_level(log, "ERROR"),
        count_level(log, "WARN"),
        count_level(log, "INFO")
    )
}

Hidden tests the grader adds (in teacher/grading/hw2-hidden-tests.rs): an empty log summarises as "0 lines: 0 ERROR, 0 WARN, 0 INFO"; longest_line("") is ""; a tie returns the first line; a level named mid-line isn't counted; a secret that repeats is redacted every time and a missing one changes nothing; first_word of an empty string or one starting with a space is ""; shouting an empty String gives "!".

Quiz 2 answer key

Extensions for fast students

  • Write fn split_command(cmd: &str) -> (&str, &str) that returns the verb and the rest, both as slices.
  • Make first_word work on non-ASCII text using char_indices().
  • Rewrite count_level with .lines().filter(...).count(). (Preview of iterators in Session 4.)
  • Explain, in two sentences, why puzzle 4 would be a crash in C++ but is a compile error in Rust.
